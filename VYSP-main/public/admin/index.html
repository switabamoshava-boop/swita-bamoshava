קוד הגישה עדיין לא הוגדר

האתר עובד, אבל הכניסה לניהול סגורה עד שמגדירים קוד גישה. עושים את זה פעם אחת בלבד, בלוח הבקרה של Cloudflare:

  1. נכנסים אל dash.cloudflare.com ובוחרים Workers & Pages.
  2. לוחצים על zimmer-gallery, ואז על הלשונית Settings.
  3. באזור Variables and Secrets לוחצים + Add.
  4. בוחרים Type: Secret, בשם המשתנה כותבים ADMIN_TOKEN, ובערך מדביקים קוד ארוך שבחרתם.
  5. לוחצים Deploy, מחכים כחצי דקה ומרעננים את הדף הזה.

ההוראות המלאות נמצאות בקובץ README שבמאגר הקוד.
